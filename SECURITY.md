# Security Policy

## Supported Versions

Seek is under active construction. As of the initial release, the following
versions receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take security issues seriously. If you believe you have found a
vulnerability in seek, please report it **privately** so it can be fixed before
public disclosure.

Do **not** report security issues through the public issue tracker or a pull
request — that would expose the vulnerability to anyone before it is patched.

### How to report

1. **Open a private security advisory** in this repository:
   GitHub → *Security* tab → *Report a vulnerability* → *Advisories*.
   This creates a private report visible only to the maintainers.

2. Provide as much detail as you can:
   - The affected component (backend / tui / webui / gui) and version.
   - Steps to reproduce.
   - A description of the impact (what an attacker could do).
   - Any suggested fix, if you have one.

### What to expect

- We will acknowledge your report within a few business days.
- We will keep you updated as we investigate and prepare a fix.
- Once the issue is resolved, we may credit you in the advisory / changelog
  (if you are comfortable with that).

We ask that you give us a reasonable amount of time to respond, investigate, and
release a fix before publicly disclosing the issue. We aim to handle reports
promptly and responsibly.

## Scope

Security reports apply to the seek source code and the official installers
produced by this repository. If you found a vulnerability in a dependency, please
also mention the upstream package so we can coordinate a fix.

Thank you for helping keep seek — and its users — safe.
